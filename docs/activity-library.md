# Activity Library (คลังรูปแบบกิจกรรม)

ใช้โดย `creative-director` และ `curriculum-designer` เพื่อไม่ให้สินค้าแต่ละชิ้นเป็น "ใบงานเติมคำตอบ" แบบเดิม ๆ
ทุกกิจกรรมต้อง **พิมพ์ขาว-ดำได้** และใช้ได้แบบ no-prep หรือ low-prep

รหัส (ID) ใช้บันทึกใน `products/catalog.json` → `activities`

## A. ฝึกทักษะพื้นฐาน (Practice)
| ID | กิจกรรม | คำอธิบาย | Prep |
|---|---|---|---|
| `fill-in` | Fill-in practice | โจทย์ + เส้นเขียนคำตอบ | none |
| `vertical-practice` | Vertical problems | โจทย์คณิตแนวตั้งในกล่อง | none |
| `match-up` | Matching | ลากเส้นจับคู่ 2 คอลัมน์ | none |
| `cut-paste` | Cut & paste | ตัดคำตอบแปะในช่อง | low |
| `sort` | Sorting mat | แยกการ์ดเป็น 2–3 กลุ่มตามเกณฑ์ | low |
| `trace-write` | Trace & write | ลากเส้นตามแล้วเขียนเอง (K–1) | none |
| `draw-model` | Draw a model | วาดภาพแทนจำนวน/แนวคิด (base-ten, number line) | none |

## กติกาการผสมกิจกรรม (Activity Mix Rules)
- สินค้า 1 ชิ้นควรมี **อย่างน้อย 3 หมวด (A–F)** และ **อย่างน้อย 4 กิจกรรมต่างกัน**
- หมวด A ต้องไม่เกิน **50%** ของหน้านักเรียน
- ต้องมีกิจกรรมจากหมวด B หรือ C อย่างน้อย 1 อย่าง (ตัว "ว้าว" ที่ใช้ทำ thumbnail)
- ดูกฎกันซ้ำข้ามสินค้าได้ใน `docs/variety-policy.md`
