# Variety Policy (กติกากันซ้ำ)

ร้านนี้ออกสินค้าใหม่ **ทุกวัน** ถ้าหน้าตาเหมือนกันหมด ครูจะเลื่อนผ่าน และร้านจะดูเหมือน "โรงงานใบงาน"
กติกานี้ใช้โดย `creative-director` (บังคับใช้), `market-researcher`, `curriculum-designer` และ `quality-reviewer` (ตรวจ)

ข้อมูลอ้างอิงคือ `products/catalog.json` ซึ่งเรียงสินค้าจากใหม่ไปเก่า สรุปการใช้งานล่าสุดได้ด้วย:
```bash
node scripts/variety-report.mjs          # ดู 10 ชิ้นล่าสุด
node scripts/variety-report.mjs 20       # ดู 20 ชิ้นล่าสุด
```

## 1. หัวข้อ & กลุ่มลูกค้า
- ห้ามสินค้า **หัวข้อหลักเดียวกัน + ระดับชั้นเดียวกัน** ซ้ำภายใน 30 ชิ้นล่าสุด
  - ข้อยกเว้น: ตั้งใจทำ **series / reskin ตามฤดูกาล** ให้ระบุ `series` ใน catalog และต้องเปลี่ยนธีม, ตัวละคร/บริบท และกิจกรรม "ว้าว" อย่างน้อย 1 อย่าง
- ใน 7 ชิ้นล่าสุด ต้องมี **อย่างน้อย 2 วิชา** และ **อย่างน้อย 2 ระดับชั้น**

## 2. ดีไซน์
- **ธีมดีไซน์** (`templates/themes/`) ห้ามใช้ซ้ำใน **3 ชิ้นล่าสุด**
- **โทนสีของ thumbnail** ต้องต่างจากชิ้นก่อนหน้า
- **คอนเซปต์ / hook** (เช่น "Subtraction Detectives", "Math Mission to Mars") ห้ามซ้ำทั้งร้าน ยกเว้นตั้งใจทำเป็น series

## 3. กิจกรรม
- ทำตามกติกาผสมกิจกรรมใน `docs/activity-library.md`
- กิจกรรม "ว้าว" (`hero_activity`) ห้ามซ้ำใน **5 ชิ้นล่าสุด**
- ใน 10 ชิ้นล่าสุด กิจกรรมใดก็ตามห้ามปรากฏเกิน **6 ชิ้น**

## 4. เนื้อหา
- ห้ามคัดลอกโจทย์จากสินค้าเก่าของร้าน (QA สุ่มเทียบ)
- ชื่อคนในโจทย์ปัญหาและบริบทต้องเปลี่ยนไปในแต่ละชิ้น

## 5. ความน่าดึงดูด (Appeal Checklist) — ตรวจก่อนลงขาย
- [ ] thumbnail ภาพแรกบอกได้ภายใน 2 วินาทีว่า "นี่คืออะไร สำหรับชั้นไหน"
- [ ] มีกิจกรรมอย่างน้อย 1 อย่างที่เด็ก "อยากทำ" (เกม / ภาพลับ / ปริศนา / ภารกิจ)
- [ ] มีคอนเซปต์หรือเรื่องราวที่ร้อยทั้งชุดเข้าด้วยกัน ไม่ใช่แค่หน้าใบงานเรียงกัน
- [ ] หน้าปกและ thumbnail ไม่ซ้ำกับ 5 ชิ้นล่าสุดเมื่อวางเรียงกัน
