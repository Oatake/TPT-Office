# TPT AI Policy: Where the Line Is (research brief)

Researched: 2026-11-02 by Market Researcher agent. Status: **the policy was announced but no written TPT policy text was found.** Re-check before each listing goes live.

> **How this was researched (please read).** In this session, direct page fetches to `www.chalkbeat.org` and `help.teacherspayteachers.com` failed (DNS blocked by the session's network allowlist), so no pages were read in full. Everything below comes from web-search result summaries and snippets of the URLs cited. **Quotes are as they appeared in search snippets. Check them against the live pages** (allow those domains, or open them in a browser) before relying on exact wording.
>
> **Source tiers.** T1 = official TPT (Help Center, Seller Agreement, Seller Blog, newsroom). T2 = reputable press. T3 = industry or seller blogs and secondary summaries. T4 = advocacy (for example, petitions).

## TL;DR

1. At its **Seller Town Hall on Oct 8, 2026**, TPT announced that it will become an "AI-free" marketplace. Sellers were told to **stop using AI-generated text and images** in resources **and** in listings (covers, thumbnails, previews, descriptions), and to **start replacing AI content in products already published** (T2/T3). A TPT spokesperson told Chalkbeat that resources "should be unique, expertly crafted, and AI-free" and that TPT is "building tools that will speed up our ability to identify and remove AI-generated resources" (T2).
2. **No written policy, effective date, penalty schedule, or grandfathering rule had been published** as of the latest sources found (Spylore, checked Oct 25, 2026). TPT promised detailed guidelines "in the coming weeks" (T3). One outlet says the ban took effect Oct 15, 2026, but that contradicts Chalkbeat, which calls the policy "forthcoming" (T3 vs T2).
3. The **AI-generated product content itself is clearly banned**: questions, passages, clip art, covers, listing copy. **Behind-the-scenes help** (brainstorming, keyword research, proofreading, layout tooling, answer checking) is **not addressed in any official text**. Treat it as *Unclear* and get written confirmation from TPT Seller Support. For our store, the biggest exposure is **inline SVG art drawn by an AI agent**, which should be treated as an AI-generated image (recommendation).

## 2. Allowed / Banned / Unclear matrix

"Banned" means multiple T2/T3 sources report it as within the announced ban. Nothing on this list is confirmed by T1 text. "Unclear" means no source addresses it, or sources conflict.

| Use of AI | Status | Basis |
|---|---|---|
| AI-written questions, passages, word problems, instructions (in the resource) | **Banned** | "stop using AI-generated ... text" in resources (rows 3, 4) |
| AI-generated clip art / illustrations / images inside resources | **Banned** | "stop using AI-generated images" (rows 3, 4) |
| AI-generated covers, thumbnails, preview images | **Banned** | Scope includes "covers, previews" (row 4); replace covers/thumbnails first (row 5) |
| AI-written listing title / description / marketing copy on TPT | **Banned** | Ban extends to "listings" (rows 3, 4) |
| Keeping old AI content in already-published products | **Banned (phase-out)** | Told to begin replacing (rows 3, 5). Deadline unknown |
| AI-drafted text that a human then substantially rewrites | **Unclear** | Tech Edvocate says handling of "initial drafts that are heavily edited by a human" is unclear (row 7). Petition reads the ban as covering all AI-assisted content (row 9) |
| Brainstorming ideas / topics with AI | **Unclear (lower risk)** | Mike Lane: TPT "did not prohibit AI-assisted brainstorming" at the announcement; the focus was on AI content in finished resources and listings (row 3). Tech Edvocate: unclear (row 7). Not in any T1 text |
| Market / keyword / competitor research with AI | **Unclear (lower risk)** | No source addresses it. Nothing AI-made ends up in the product |
| Spell / grammar check (traditional checkers) | **Unclear** | No TPT source. Generative "rewrite" features (for example, AI suggestions that rephrase sentences) are higher risk than error flagging |
| Machine / AI translation (for example, Spanish versions) | **Unclear (high risk)** | No TPT source. The output is text the seller did not write, so it is functionally AI-generated text |
| Answer-key verification by AI (human writes the key, AI double-checks) | **Unclear (lower risk)** | No source. Nothing AI-made ends up in the product if the human makes the corrections |
| Layout / formatting tools (templates, auto-layout, PDF build scripts) | **Unclear** | Sellers worry about "formatting or other behind-the-scenes help" (Bright Learning / Tech Edvocate snippets). No ruling |
| AI features inside design tools (for example, Canva Magic tools) | **Unclear → treat as Banned if they generate images or text** | No TPT source. Canva's own terms say AI output may not be copyright-clear and ask for disclosure ([Canva AI Product Terms archive](https://www.canva.com/policies/ai-product-terms-2025-11-28/)) |

### Q3: Disclosure requirement
- **No official TPT "substantially AI-generated" disclosure rule was found** in any T1 source during this research. Chalkbeat (Aug 2026, T2) saw sellers voluntarily placing AI disclosures on listings, which reads as seller practice rather than a TPT requirement.
- **Status under the ban (inference, not fact):** a disclosure regime is not compatible with an "AI-free" marketplace. If an older disclosure rule existed, it has likely been **superseded**. Disclosing AI content would not make it allowed, and could flag the listing. **Confirm with Seller Support** (question 3 below).

### Q4: Seller-community reports
- **Petition:** Change.org "Reevaluate TPT's AI content policies" (T4). Snippet shows about 212 (label unclear).
- **Takedowns / false positives:** Search summaries mention creators in seller Facebook groups complaining that stores were penalized over **suspected** AI use. Analysts warn that detectors produce false positives, and that a detection result alone does not prove a policy violation (T3, via Bright Learning / Spylore snippets). **No quantified takedown numbers and no confirmed individual cases were found.**
- **Practical advice circulating (T3):** save a dated copy of TPT's guidance, keep records of your own drafting and editing process, avoid AI text/images in finished files and listings, and ask Support about specific workflows ([Spylore](https://www.spylore.com/blog/teachers-pay-teachers-ai-ban-2026), [Mike Lane](https://mikellane.com/tpt-ai-policy/)). Mike Lane notes TPT has not announced a documentation requirement, but says keeping records is sensible.

## 3. Implications for our assets (analysis, labeled)

| Asset | Assessment | Reasoning |
|---|---|---|
| **Inline SVG art drawn by an AI agent in code** (themes, decorations, icons, clip art) | **Treat as Banned (recommendation)** | The ban covers AI-generated *images* (rows 3, 4). An image is still AI-generated whether the AI outputs pixels or SVG path code. A detector or reviewer sees the rendered art, not the method. The US Copyright Office also treats AI-determined expressive elements as lacking human authorship ([USCO Copyrightability Report, Jan 2025](https://www.copyright.gov/ai/Copyright-and-Artificial-Intelligence-Part-2-Copyrightability-Report.pdf)), which weakens our "original work" claim under TPT's IP policy (row 11) |
| **Fonts (SIL OFL 1.1 / Apache 2.0)**: Andika, Fredoka, Baloo 2, Patrick Hand, Sniglet, Lexend, Luckiest Guy (`brand/assets/LICENSES.md`) | **Allowed (high confidence)** | These are human-designed, commercially licensed fonts, so they are not AI output. The OFL permits embedding in sold PDFs. Keep `LICENSES.md` current |
| **Layout code generated by AI** (`templates/*.html`, `templates/themes/*.css`, `scripts/build-pdf.mjs`) | **Unclear. Tooling likely low risk, visual design moderate risk** | The build script is software, like any PDF tool, and is not "resource content". But AI-designed decorative layouts (borders, backgrounds, ornament motifs) are part of what the buyer sees. Plain structural layout (boxes, lines, grids, answer blanks) is the safest. Ask Support (question 5) |
| **Existing products** (`products/catalog.json` lists 1 product: `2nd-grade-regroup-or-not-subtraction`) | **Audit now (recommendation)** | If any of its text, art, cover, preview or listing was AI-generated and it is live on TPT, then by the Oct 8 instruction (row 3) it must be replaced. Start with the cover/thumbnail (row 5) |
| **Agent-generated listing / marketing copy** (`05-listing`, `07-marketing`) | **Banned for TPT listings** | Listings are in scope (rows 3, 4). The owner must write the listing copy |

## 4. Open questions for TPT Seller Support

Ask in writing and keep the reply (screenshot and date). Questions:
1. Is the written AI policy published yet? What is the URL, and what is the effective date / deadline for existing listings?
2. Which uses are acceptable *if no AI-generated text or images appear in the final resource or listing*: brainstorming, keyword research, error-flagging spell check, answer-key double-checking?
3. Is an older AI-disclosure practice still relevant, or does disclosure no longer make AI content acceptable?
4. Is text a human wrote from scratch, after reviewing an AI outline or plan, acceptable? Is an AI draft that is fully rewritten acceptable?
5. Are AI-assisted layout/formatting tools (code that arranges human-written content into a PDF) acceptable? Does decorative vector art produced by AI-written code count as an AI-generated image?
6. Is machine translation of the seller's own human-written resource allowed?
7. How will detection work? If a resource is flagged by mistake, what is the appeal process, and what evidence (drafts, process records) will TPT accept?
8. What are the penalties: listing removal, store demotion, or account closure?

## 5. Recommended human-in-the-loop workflow

**These are recommendations based on the reported scope, not TPT-confirmed rules.** Tighten or loosen them once Support replies.

Rule of thumb (recommendation): **every word and every image a buyer can see, in the file, cover, preview, thumbnail and listing, must be made by the owner** (or be licensed human-made art or fonts). Agents may only produce internal working documents that never ship, plus checks that the owner acts on personally.

| Step | Owner must personally do | Agents may still do (recommended) |
|---|---|---|
| 01 Research | Pick the final idea | Market/keyword/competitor research, variety-report checks (internal docs only) |
| 02 Curriculum plan | Approve the standards and skill scope | Map standards and list skill targets as an internal checklist. **Do not draft items** |
| 03 Content | **Write every question, passage, word problem, instruction and answer key** | Check math/answers and flag errors (the owner fixes them), check reading level, find typos (flag only, never rewrite), check standards alignment |
| 04 Design | **Draw or choose all art.** Use owner-drawn art or licensed human-made clip art with a license stating it is not AI-made. **Retire agent-drawn SVG illustrations** | Typesetting with plain structural layout (grids, lines, answer boxes), applying licensed fonts, running `build-pdf.mjs`, pagination/print checks |
| 05 QA | Final read-through and sign-off | `quality-reviewer` checks for errors, accessibility, print margins, license gaps, and **"AI-free" compliance** (no agent-authored text or art in the output) |
| 06 Listing | **Write title, description, tags/keywords text, cover and preview text** | Supply a keyword list and a character-limit/SEO checklist. **No drafted copy** |
| 07 Marketing (off-TPT) | Write anything that links to or represents the TPT product | Scheduling and analytics. Avoid AI copy that is reused on TPT |
| Records | Keep dated drafts and source files (for example, handwritten scans, edit history) for appeals | Archive the version history in `products/<slug>/` |

**Immediate actions (recommendation):**
1. Send the Support message above. Do not publish new listings until the reply arrives, or publish only fully owner-made items.
2. Audit `2nd-grade-regroup-or-not-subtraction`. If it is live and contains agent-written text or agent-drawn SVG art, unpublish or replace it, starting with the cover and thumbnail.
3. Update the agent role files (`.claude/agents/content-writer.md`, `worksheet-designer.md`, `tpt-listing-specialist.md`) so agents stop producing shippable text and art. This is a separate task: not done here per the brief.
4. Re-run this research once TPT publishes its written policy, and replace the T3 rows with T1 text.

## Owner Decision (2026-11-06) — Approach A
- **Decision:** keep the full AI-team pipeline and continue selling on TPT, because TPT has not published official written policy text (only press reports / town-hall recaps).
- **Guardrails while the policy is unofficial:**
  1. Listings, covers and marketing must **never claim** "handmade", "AI-free", "100% teacher-written" or similar.
  2. Before every new upload, `quality-reviewer` re-checks for an official TPT policy page (Help Center / Seller Agreement). If an official ban is published, stop uploads and report to the owner.
  3. `products/catalog.json` keeps every product's files so listings can be pulled or replaced quickly if the policy becomes official.
- **Risk acknowledged by owner:** TPT's spokesperson told Chalkbeat the marketplace will be "AI-free" and that detection/removal tools are being built; listed products could be removed later.
