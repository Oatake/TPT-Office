## Learning Objectives

Students will be able to…
1. **partition** a number line from 0 to 1 into 2, 3, 4, 6, or 8 equal parts and **name the size of one part** as a unit fraction 1/b. *(3.NF.A.2a)*
2. **locate and label** the unit fraction 1/b as the endpoint of the first equal part from 0. *(3.NF.A.2a)*
3. **name and place** a fraction a/b on a number line by marking off a lengths of 1/b from 0, counting the **intervals (hops), not the tick marks**. *(3.NF.A.2b)*
4. **place** fractions greater than 1 (such as 5/4 or 7/3) on number lines that extend past 1. *(3.NF.A.2b)*
5. **explain** that two fractions are equivalent when they land on the **same point** of a number line, and **generate** simple equivalent fractions (e.g., 1/2 = 2/4 = 3/6 = 4/8, 2/3 = 4/6). *(3.NF.A.3a, 3.NF.A.3b)*
6. **express** whole numbers as fractions (e.g., 1 = 4/4, 2 = 6/3, 3 = 3/1) and locate them at the same point as the whole number. *(3.NF.A.3c)*
7. **find and fix** number line errors (counting tick marks, unequal parts, starting the count at 1, flipping numerator and denominator) and justify claims using a number line. *(3.NF.A.2, 3.NF.A.3a)*

**Key vocabulary (student-facing, ต้องอยู่บน Trail Guide p.3):** number line, fraction, numerator, denominator, equal parts, unit fraction, whole, tick mark, interval, equivalent, same point
**Routine ประจำชุด (ทุกหน้า):** *1. Count the hops. 2. Name one hop. 3. Hop to the spot.* ใช้คู่กับคำจริงเสมอ เช่น "each hop (equal part)"

## Maze Spec (pp. 6, 7, 9) — สำคัญที่สุดของชุด

**โครง:** ตาราง **4 คอลัมน์ × 5 แถว = 20 trail signs** ระบุช่องเป็น R1C1 (ซ้ายบน) … R5C4 (ขวาล่าง) โดย **Base Camp** (ธง) อยู่นอกตารางเหนือ R1C1 และ **Cocoa Cabin** อยู่นอกตารางใต้ R5C4 ส่วน R1C1 และ R5C4 ต้องเป็นช่องที่ถูกเสมอ
**Directions (ใช้ทั้ง 3 หน้า):** *"Start at Base Camp. Read each trail sign. Does the fraction name the footprint? If YES, color the circle and hop to the next sign: up, down, left, or right (no diagonals). Only true signs lead to the Cocoa Cabin!"* (Maze 3 ใช้ "Does the fraction land on the same spot?")
**Self-check ที่ Cabin:** *"The right trail has 10 footprints. Count yours!"* (Maze 2 = 12)

**กฎการสร้าง (content writer ต้องตรวจทุกข้อ):**
1. **ช่องที่ถูก (true) = ช่องบน path เท่านั้น** ช่องนอก path ทั้งหมดต้องเป็น false
2. path ต้อง**ไม่แตะตัวเอง**: ช่องบน path 2 ช่องที่ไม่ได้อยู่ติดกันตามลำดับต้องไม่อยู่ติดกัน (กันทางลัด) ซึ่งทำให้มีทางที่ถูกเพียงทางเดียว
3. path ต้องคดเคี้ยว: มีการเลี้ยวอย่างน้อย 4 ครั้ง และต้องเดินขึ้นหรือซ้ายอย่างน้อย 1 ครั้ง (Maze 2–3) เพื่อไม่ให้เดาได้ว่า "ลงกับขวาเสมอ"
4. ที่ทุกจุดเลี้ยว ต้องมีช่อง false ติดกันอย่างน้อย 1 ช่องเป็นทางเลือกล่อ
5. ใน maze เดียวกัน ตัวส่วน 2, 3, 4, 6, 8 ต้องปรากฏทุกตัวในช่อง true และต้องไม่มีสองช่องที่เหมือนกันทุกประการ
6. ตัวลวงทุกช่องต้องมี **misconception code** (ด้านล่าง) และแจกแจงใน 03-content.md
7. **ตัวส่วน 5, 7, 9** ใช้ได้เฉพาะตัวลวง **M1** (นับ tick) และไม่เกิน **2 ช่องต่อ maze** (ยกเว้นที่บังคับ: Maze 2 ต้องมี "3/5 บนเส้น fourths จุดที่ 3/4" สำหรับ thumbnail) ห้ามมี 10 หรือ 12 เด็ดขาด
8. ส่ง maze เป็นตาราง markdown 4 × 5 (แต่ละช่อง: `NL[...]` + ป้ายเศษส่วน + T/F + code) + รายการ path ตามลำดับ (เช่น R1C1 → R2C1 → …) + จำนวนช่อง และ**ตรวจกฎ 1–7 ซ้ำ 2 รอบ**

**Maze 1: Unit Fractions (p.6, 2a)** — ทุกช่อง `NL[0–1, b, labels=0,1]` + จุด + ป้าย 1 ตัว
- true 10 ช่อง: จุดที่ 1/b + ป้าย 1/b (ตัวส่วนทั้ง 5 ตัว ตัวละ ≥ 2 ช่อง)
- false 10 ช่อง: M1 ×3 (เน้น halves→1/3, thirds→1/4 ให้ใช้ตัวส่วนในขอบเขต), M2 ×2, M3 ×2, M4 ×2, M5 ×1

**Maze 2: Fractions on a Number Line (p.7, 2b)** — `NL[0–1, b]` และ `NL[0–2, b ∈ {2,3,4}, labels=0,1,2]` 3 ช่อง
- true 12 ช่อง: a/b (a ≥ 2 อย่างน้อย 9 ช่อง), ช่อง > 1 อย่างน้อย 2 ช่องอยู่บน path
- false 8 ช่อง: M1 ×2 (รวม "3/5"), M2 ×2, M3 ×2, M4 ×1, M6 ×1

**Maze 3: Same Spot or Whole Number? (p.9, 3a/3c)**
- ช่อง "Same spot?" 12 ช่อง: เส้นซ้อน 2 เส้น (0 และ 1 ตรงกัน) **เส้นบนมีจุด + ป้าย, เส้นล่างมี tick แต่ไม่มีจุด และมีป้ายเศษส่วนที่อ้างว่าเท่ากัน** (นักเรียนต้องนับ hop บนเส้นล่างเองเพื่อตรวจ ห้ามวาดจุดล่างให้เห็น) คู่ตัวส่วนที่ใช้: 2↔4, 2↔6, 2↔8, 3↔6, 4↔8 (ทั้งสองทิศ)
- ช่อง "Whole number?" 8 ช่อง: `NL[0–2 หรือ 0–3, b]` จุดที่ 1, 2 หรือ 3 + ป้ายเศษส่วน (เช่น 8/4, 6/2, 3/3) **เส้น 0–3 ใช้ b = 2 เท่านั้น** (6 hop) เพื่อให้อ่านได้ในช่องเล็ก
- true 10 ช่อง (คู่ equivalent ที่อนุญาต: 1/2 = 2/4 = 3/6 = 4/8, 1/3 = 2/6, 2/3 = 4/6, 1/4 = 2/8, 3/4 = 6/8 และจำนวนเต็ม 1 = b/b, 2 = 2b/b, 3 = 6/2)
- false 10 ช่อง: M3 ×1, M7 ×3, M8 ×3, M9 ×2, M2 ×1

2. เศษส่วนที่มากกว่า 1 อยู่**บนเส้น 0–2 หรือ 0–3 เท่านั้น** และใช้เฉพาะ p.5 (ข้อ 10), p.7, p.8 Part C, p.9, p.12, p.13 ข้อ 8 (ยกเว้นตัวอย่างใน p.11 ข้อ 2 ซึ่งเป็นการพิสูจน์ในกล่อง Prove it)
3. **ไม่ใช้ mixed numbers** (1 1/4) และ**ไม่ใช้คำว่า "improper fraction", "simplify", "reduce", "simplest form"** (ไม่อยู่ในมาตรฐาน ป.3) ให้ใช้คำว่า "fractions greater than 1"
4. คำตอบ "Name the point" ใช้ตัวส่วนตามจำนวน hop ของเส้นนั้น (จุดที่ 2/4 บนเส้น fourths → 2/4) Answer key ต้องเขียนหมายเหตุ "Also accept 1/2 if the student explains it is the same point." ทุกจุดที่มีคำตอบเทียบเท่าได้
5. **ห้ามใช้โจทย์ซ้ำข้ามหน้า** (รวม Trail Guide, worked example, tickets, quick check) โดยแต่ละหน้ามีตาราง "Used points" ท้ายหน้าเพื่อตรวจซ้ำ
6. ระบุทุกเส้นจำนวนด้วยสัญลักษณ์ `NL[...]` และใต้แต่ละหน้าใส่**ตารางตรวจ**: ข้อ / NL / คำตอบ / ตรวจ (นับ hop จาก 0) / code (ถ้าเป็นตัวลวง) **คำนวณซ้ำ 2 รอบ**
7. ข้อ p.10 ใบ 2 (hop ไม่เท่ากัน) ให้ระบุสัดส่วนความยาวของแต่ละช่วงเป็นตัวเลข เพื่อให้ designer วาดได้แม่นยำ

### ภาษาและคอนเซปต์
- Directions ระดับ ป.3: ประโยคละไม่เกิน 15 คำ ขึ้นต้นด้วยคำกริยา คำศัพท์จริงต้องอยู่คู่กับคำ routine เช่น "Count the hops (equal parts) from 0 to 1."
- ชื่อหน้าและ flavor line ใช้ตาม outline (มาจาก Page Title Rewrites ใน brief) ชื่อห้ามเกิน ~36 ตัวอักษร
- Juniper = **she**, Birch = **he** ใช้สม่ำเสมอ ส่วนคนใน p.10 ใช้ **Nadia, Emeka, Lucia, Tobias** (ตรวจแล้วว่าไม่ซ้ำกับชื่อในสินค้าก่อนหน้า) ไม่มี word problems ในชุดนี้
- **คำต้องห้าม:** Christmas, holiday, Santa, reindeer, elf, gingerbread, candy cane, ornament, present/gift, Merry, December, Hanukkah/Kwanzaa และคำเทศกาลอื่น ๆ บริบทที่ใช้ได้: snow, trail, pine trees, mountains, cabin, hot cocoa, scarf, hat, snowshoes, snowflakes, snowballs, mittens
- ภาพทั้งหมดให้เขียนเป็น `[IMAGE: ...]` ที่อ้าง SVG ใน creative brief (#1–#15) เท่านั้น
- Sentence frames: "The mistake is ___." / "I know because ___." / "They land on the same spot, so ___." / "Each hop is ___, so ___ hops is ___."

### Answer keys
- ทุกหน้ามีเฉลยครบ ข้อที่ open-ended ให้ใส่**ทุกคำตอบที่เป็นไปได้ภายในตัวส่วน 2–8** + "Answers will vary." + ตัวอย่างคำอธิบาย 1 ตัวอย่าง
- Maze: path ตามลำดับ + จำนวนรอยเท้า + ทุกช่อง false มี code
- Game Answer Card: ตาราง 5 × 5 ตรงตำแหน่งกับกระดาน และระบุคำตอบเทียบเท่าที่รับได้ (เช่น "4/4 (or 1)")

## ข้อกำหนดสำหรับ Worksheet Designer

### พื้นฐาน
- ธีม **`clean-minimal`** + `html:root` override ตาม creative brief (glacier `#2468a0`, berry `#c8325f`, ice/snow เฉพาะปกและ thumbnail) **ห้ามแก้ไฟล์ธีม**
- ทุกหน้านักเรียน (pp. 4–14) มี **name line**, paws ที่มุมขวาบน (ยกเว้น p.13–14 ที่ไม่มีระดับ) และ footer = ชื่อร้าน + เลขหน้า + **รหัสมาตรฐานตัวเล็ก** (เช่น "3.NF.A.2a")
- พื้นขาวล้วน ห้ามพื้นทึบ และตรวจ grayscale ทุกหน้า (เส้นโค้ง berry ต้องยังเห็นชัด)
- เศษส่วนเป็นแบบตั้ง (HTML/CSS หรือ SVG `<text>` + เส้นคั่น) **ห้ามใช้ ½ ¼ ¾ ⅛ / U+2044** ตัวเศษและตัวส่วนบนหน้านักเรียนต้อง **≥ 12 pt** และห้ามใช้ ★ ✓ • → ❄ หรือ emoji (ใช้ SVG) จากนั้นตรวจ `pdffonts` ว่ามีแค่ Lexend

### Number line generator (`#numline`)
- คำนวณตำแหน่ง tick ด้วยสูตร `x = x0 + (k / (b × (max − min))) × L` ห้ามวางด้วยมือ และรองรับพารามิเตอร์ตามสัญลักษณ์ `NL[min–max, b, point, labels, guide]`
- เส้นหลักหนา ≥ 2 pt, tick ~0.18 in (tick ที่จำนวนเต็มยาวกว่าเล็กน้อย ~0.24 in), จุดเป็น footprint ทึบ (SVG #5) หรือวงกลมทึบ ≥ 0.12 in
- **ความยาวขั้นต่ำ:** หน้าฝึกที่นักเรียนเขียนใต้ tick หรือวาด hop (p.3, 4, 5 Part B, 8) ≥ 5.5 in / p.5 Part A, p.11 ~3.2–4 in / exit tickets ~3 in / ช่อง maze ~1.4 in / ช่องเกม ~1.2 in
- เส้นในช่อง maze และเกม: label เฉพาะ 0, 1 (และ 2, 3) ขนาด ≥ 12 pt และไม่เกิน 8 hop ต่อเส้น (เส้น 0–2 fourths = 8 พอดี)
- เส้นซ้อน (p.8, p.9, p.12): 0 และ 1 ต้องตรงกันในแนวตั้งแม่นยำ (ใช้ x0 และ L เดียวกัน) มีเส้นประแนวตั้ง berry เฉพาะในตัวอย่างและ answer key
